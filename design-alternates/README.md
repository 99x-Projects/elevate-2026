reference. The live site is the dark version at the repo root (`index.html`).

- `index-new.html`   — light Nordic, single teal accent, dark "Why" band
- `index-earth.html` — light + the four 99x pillar colours (terracotta / olive / ochre / coral)
- `index-plum.html`  — light, purple + coral blend accent
- `index-green.html` — light, green accent
- `index-teal.html`  — light, teal accent
